# Daily planning and review tools

Implemented on 2026-11-26, following the three improvements released in `222c6cc`. The owner approved commit and deployment after local verification. The exact release commit and hosting result are reported in the chat handoff.

## Delivered behavior

1. **Daily planning:** Today retains the existing synced focus and adds up to two optional tasks, direct access to overdue work and active projects, and the weekly review link. Optional choices reset on a new local calendar day; they do not move deadlines.
2. **Undo:** Confirmed task completion, capture archiving, habit check-in and positive habit/water additions offer a 15-second Undo message. Task undo restores the prior status; capture undo restores only the archive flag; habit undo subtracts the confirmed addition while retaining the date's target. Existing binary undo and quantity correction controls remain. Undo is blocked during duplicate submissions, after later local changes, on account mismatch, or when guarded database values no longer match. Failures do not claim success. An uncertain response may require reloading the affected list to see the saved result. Destructive task deletion is not newly reversible.
3. **Weekly review:** `/review`, available from Today and More/navigation, reviews the last seven local dates. It shows unfinished work, currently done tasks completed in the period, projects to revisit, an unsorted capture count, and habit target-day comparisons against the prior seven days. No journal body is read. Project criteria are explicit: active projects without an open next task or without a task completed in the period, rather than an invented activity history. Up to three selected tasks form next week's priorities; they remain visible during that target week. Starting the following week's plan explicitly clears those choices. No task deadline or status changes automatically.
4. **Customize Today:** Pin shortcuts for capture, quantity logging, Journal, Casebook, Tasks, Projects or review. Quantity logging opens the owner's existing active quantity habits; it creates no prescribed water goal. Hide capture, habits, reminders, radar, puzzle or wrap-up sections. Focus/planning and Reset layout stay accessible.
5. **Quiet reminder controls:** Existing item reminder dialogs add mute/resume and task-only 15-minute/one-hour snooze. Snooze replaces the saved task reminder time from now, rounded up to the next minute, using the rule's time zone. Habit reminders remain daily; edit their time rather than replacing the schedule. Repeated daylight-saving wall times that cannot represent the intended instant are rejected with an explanation. Controls change reminder fields only, guarded against concurrent changes; deadlines remain unchanged. Quiet hours, scheduler cadence and device permissions still apply. Already sent/in-flight pushes cannot be recalled. The notification bell labels deadline attention separately from requested push reminders.
6. **Evening wrap-up:** Today shows completed work, unfinished focus with normal task controls, and a dated Journal link. Available throughout the day, optional to hide, with no streak requirement, journal content read, or automatic rollover.
7. **Data portability:** Settings exports one selected saved collection (Tasks, Projects or Habit definitions) as JSON/CSV. Task notes/project descriptions require an unchecked explicit opt-in. Journal/Inbox writing, habit logs, unsaved drafts, credentials and recovery material are excluded. Export paginates fresh owner-filtered reads and refuses partial/error results, account changes and overly large collections. Files are unencrypted. CSV neutralizes formula-like text; JSON retains original text. This is selected-data portability, not a full backup or import feature. Concurrent edits during pagination can change the snapshot; the UI says so.

## Persistence and privacy boundary

Daily optional task IDs, weekly priority IDs and display choices are saved in account-scoped local browser storage. No task titles, journal/capture text or habit records are stored there. The UI distinguishes durable browser storage from session fallback when storage is blocked. Stale account handlers cannot update these preferences. Existing focus and reminder persistence are reused. No new dependencies, paid services, migrations, permissions, encryption model or privacy release work are introduced.

The other checkout's paused privacy work and local journal disclosure/assistant-context improvements remain untouched. Integration overlaps are the shell and app store, Inbox/habit state, and task data APIs. Journal persistence and assistant-context sources are unchanged. The new export deliberately excludes journal and Inbox text so it does not depend on the encrypted-journal milestone. Coordinate any future merge of those shared files rather than copying this store over the paused version.
